# Pixelora — Creative Digital Agency

Pixelora is a responsive landing page for a fictional creative digital agency. The project focuses on clean design, smooth interactions, and a user-friendly experience across different screen sizes.

## Features

- Responsive layout for mobile, tablet, and desktop.
- Sticky navigation bar with active section highlighting.
- Mobile navigation menu with smooth transitions.
- Hero section with custom visual elements.
- Services section featuring three main services.
- About section highlighting the agency's values.
- Contact form with basic HTML validation and a feedback message.
- Floating Back to Top button.
- Scroll reveal animations.
- Accessibility improvements, including keyboard focus indicators and a skip navigation link.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

Pixelora/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional packages or installations are required.

## Important Note

The contact form currently demonstrates client-side validation and a success message. It does not send messages to a real email address or backend service.
